XEdu Client
面向教学场景的 Python / Jupyter / 课程资源管理客户端
1. Jupyter Lab 和 Blockly 是独立环境，也支持从课堂或课程资源直接打开文件。
2. 学生模式下可直接进入课堂、查看学习资源并完成学习任务。
3. 教师模式下可管理资源库、课堂设置、Python 环境与包管理。
1. 第一次使用建议先到“Python”页确认解释器路径是否正确。
2. 如果包安装失败，先检查网络与镜像源，再重试。
3. 课堂资源建议按课程统一整理，方便后续共享、发布与复用。
1. 教师先配置课程与环境。
2. 学生直接进入课堂开始学习。
3. 课程内容可持续修改、共享与共建。
