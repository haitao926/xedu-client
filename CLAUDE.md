## Design Context

### Users
Primary users are teachers and students running local notebook-based lessons in a desktop app.
They work in classroom or preparation contexts where fast task completion and low cognitive load matter.
Core jobs to be done:
- launch and manage local Jupyter environments reliably
- organize and edit course resources
- ask AI for quick help while staying in the same workflow

### Brand Personality
Professional, practical, and approachable.
The interface should feel stable and trustworthy first, then efficient and lightweight.
Emotional goals:
- confidence during setup and operations
- calm focus during teaching preparation
- clear progress and feedback while using AI and resource tools

### Aesthetic Direction
Use a clean, light, education-oriented control panel style with soft depth and restrained accent color.
Prefer strong information hierarchy over decorative complexity.
Avoid noisy novelty patterns, heavy glass effects, and "generic AI demo" visuals.

### Design Principles
1. Keep workflows obvious: every major section should reveal next actions without extra explanation.
2. Prefer text-first interaction: input intent is primary, attachments are secondary and progressively disclosed.
3. Preserve continuity: visual language should match existing components and avoid abrupt style divergence.
4. Prioritize readability: spacing rhythm, contrast, and typography must support long sessions.
5. Design for classroom reality: responsive layouts should adapt without hiding key controls.
