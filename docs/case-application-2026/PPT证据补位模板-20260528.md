# 创AI申报PPT证据补位模板

本模板用于补齐当前申报 `PPT` 最关键的四类强证据。
你只需要把空白项逐项填写即可，后续可直接回填到 `PPT` 第 `7-8` 页及相关申报材料。

## 使用说明

- 本模板只做占位，不替你虚构内容
- 文件路径可以写本地截图路径，也可以先写“待补”
- 反馈摘录建议保留原话，再另做精简版上 `PPT`
- 所有课堂照片、学生作品请先完成脱敏
