当前建议

这一页现在同时放了“可控结构图版本”和“Roil 生成版本”。下一步应当由你先判断： 是保留结构更可控的 A-F 版本，还是选择某些 Roil 图作为更接近成品汇报页的图像底图。 一旦方向确定，我再继续把它们收束到正式 PPT 中。

如果下一步继续优化图片，优先改的是“编号、分区、短标签和图注”，而不是继续追求更炫的 AI 视觉风格。
