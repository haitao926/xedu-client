# 2026 教师人工智能应用案例征集申报包

本目录基于当前 `XEdu Client` 项目整理，目标是为“2026年教师人工智能应用案例征集活动”提供一套可直接改写、转 Word、转 PPT、转视频的完整申报材料包。

目录整理约定：

- 根目录 `.md` 文稿是当前默认维护的主文稿。
- `PPT/` 和 `应用报告/` 保留最终交付物与必要过程文件。
- 已确认重复或仅用于回溯的历史副本已移动到 `archive/`。

## 申报路线

- 首选类别：`创AI`
- 建议子类：`人工智能学习工具`
- 建议案例名：`XEdu Client：面向人工智能课堂的一体化实验学习平台`
- 默认学段：`初中`
- 默认视频风格：`课堂申报风格`
- 默认演示案例：`01_目标检测与细粒度分类`

选择理由：

- 项目本质上是面向学生的人工智能学习工具，而不是单纯的教学案例展示材料。
- 项目同时覆盖 `Jupyter` 代码实践、`Blockly` 可视化理解、课程资源管理和课堂接入，符合“学用结合”的工具型成果特征。
- 指南中的“人工智能学习工具”示例明确包含可视化学习模块、算法学习与实践环境，与当前项目定位高度一致。
- `01_目标检测与细粒度分类` 同时具备 `Blockly + ipynb + py + 图片素材`，最适合拍出“可视化理解到代码实践”的学习闭环。

## 统一叙事口径

- 案例定位：`面向课堂实验的 Jupyter + Blockly 一体化人工智能学习工具`
- 目标人群：`初中人工智能通识课学生`
- 核心问题：`环境复杂、工具切换多、学习路径割裂、课堂上下文难保留`
- 核心价值：`降低入门门槛、增强课堂连续性、提高实验复现性`
- 演示主线：`教师准备课程资源 -> 学生进入 Blockly 理解任务 -> 切换到 Jupyter 继续代码实验 -> 展示结果与复盘`
