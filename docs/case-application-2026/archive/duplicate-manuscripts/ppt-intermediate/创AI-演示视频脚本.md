# 创AI演示视频脚本

总时长建议控制在 `7分30秒` 左右，符合指南中“不超过8分钟”的要求。建议形式为 `PPT + 录屏 + 解说`。本稿按 `初中学段`、`课堂申报风格`、`01_目标检测与细粒度分类` 演示主线撰写。

## 一、片头：问题与定位（约 50 秒）

- 画面：
  `PPT 封面 + 项目主界面概览`
- 讲解稿：
  `在初中人工智能通识课程中，教师常常遇到这样的问题：讲解材料、可视化练习和代码实践分散在不同工具里，学生频繁切换环境，课堂时间容易耗费在找入口、配环境和重复解释上。`
  `针对这一问题，我们开发了 XEdu Client。它是一款面向课堂实验的 Jupyter 与 Blockly 一体化人工智能学习工具，帮助学生在同一任务上下文中完成理解、操作、验证与复盘。`

## 二、功能与课堂流程（约 4 分 30 秒）

### 1. 课程资源与课堂接入（约 60 秒）

- 画面：
  `展示课程资源页，定位到 ai-showcase-exam-2025 课程，再进入 01_目标检测与细粒度分类`
- 讲解稿：
  `在使用中，教师可以先把讲解页、Blockly 工作区、Notebook、Python 文件和素材图片组织成同一门课程资源。`
  `学生进入课堂后，不需要在多个软件之间重新寻找材料，而是直接进入当前课节对应实验，从源头上减少课堂切换成本。`

### 2. Blockly 可视化理解任务流程（约 90 秒）

- 画面：
  `打开 detection_and_classification.blockly.xml，对准关键积木流程`
- 讲解稿：
  `以“目标检测与细粒度分类”为例，学生先在 Blockly 中观察任务流程。这个任务的核心逻辑是：先找到图中的动物位置，再把检测框内的区域裁剪出来，最后对裁剪结果进行分类。`
  `这种可视化呈现方式适合初中学生理解任务结构，帮助他们先建立流程意识，再进入代码层面。`

### 3. 展示运行结果与课堂观察点（约 80 秒）

- 画面：
  `展示运行按钮、结果卡片、结果图或输出区`
- 讲解稿：
  `在课堂上，教师可以结合结果区引导学生关注三个观察点：检测框是否准确、裁剪区域是否合理、分类结果是否与原图内容一致。`
  `这样，学生不只是“搭积木”，而是在结果反馈中理解每一步操作的作用。`

### 4. 从 Blockly 过渡到 Jupyter 代码实践（约 80 秒）

- 画面：
  `切到 detection_and_classification.ipynb 或 detection_and_classification.py`
- 讲解稿：
  `完成可视化理解后，学生再进入 Jupyter，继续查看和运行对应代码。`
  `这里的重点不是一下子讲深所有代码细节，而是帮助学生把前面在 Blockly 中看到的流程，对应到 Notebook 中的读图、裁剪和分类步骤，实现从图形化理解到代码实践的自然过渡。`
