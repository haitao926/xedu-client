# 创AI视频录制顺序单

按“先静态素材，后动态录屏，最后解说”的原则执行，减少返工。

## 第一步：整理静态文稿

1. 确认最终案例名、学段、作者单位写法一致。
2. 从本目录定稿以下文稿：
   `创AI-视频PPT页纲.md`
   `创AI-视频逐页口播稿.md`
   `创AI-视频成片结构单.md`
3. 先把 `[待补]` 中已有真实信息填入一版，避免后面录完再大改。

## 第二步：准备静态截图

1. 截项目主界面。
2. 截课程资源页。
3. 截目标案例资源卡。
4. 截 Blockly 关键流程区域。
5. 截 Notebook 关键代码段。
6. 截运行结果图或结果卡。
7. 整理 AI 辅助开发截图。
8. 整理课堂照片、学生作品、反馈摘录、数据图。

## 第三步：录制系统操作

1. 录课程资源页进入目标案例。
2. 录打开 Blockly 工作区。
3. 录展示关键积木流程。
4. 录运行或展示结果区。
5. 录切到 Jupyter。
6. 录展示 Notebook 关键代码和结果。

建议：

- 每个镜头至少录两遍。
- 一版正常速度，一版更慢更稳，后期更好剪。
- 运行不稳定的镜头，优先保留“已有结果展示”备份版本。

## 第四步：制作 PPT

1. 按页纲先摆内容，不急着美化。
2. 把已截好的图按页放进去。
3. 对 AI 生成图片或示意图加 `AI生成` 标注。
4. 检查全片不出现网址、二维码、联系方式。

## 第五步：录制解说

1. 先通读逐页口播稿两遍。
2. 先录一版连续通稿。
3. 再按页补录发音不稳或节奏不好的片段。
4. 语速按 `每分钟 180-220 字` 控制，避免超时。

## 第六步：合成与复核

1. 按 `创AI-视频成片结构单.md` 拼接视频。
2. 插入 PPT、录屏、静态图和解说。
3. 检查总时长是否小于 8 分钟。
4. 检查 AI 标注、隐私保护、声音清晰度和片尾完整性。
