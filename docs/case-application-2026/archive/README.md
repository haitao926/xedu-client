# 案例包归档区

本目录用于收纳 `docs/case-application-2026/` 下已经确认不再作为主入口维护的重复文件和历史副本。

当前分类：

- `duplicate-manuscripts/`：与根目录主文稿内容重复的中间副本文稿。
- `duplicate-generators/`：与案例包根目录脚本重复的生成脚本副本。
- `duplicate-docx/`：与交付目录或当前工作目录重复的历史 `docx` 副本。

保留原则：

- 案例包根目录中的 `.md` 主文稿仍是默认编辑入口。
- `deliverables/`、`PPT/`、`应用报告/` 中的最终交付文件继续原位保留。
- 归档内容只做回溯用途，不再作为默认编辑目标。
