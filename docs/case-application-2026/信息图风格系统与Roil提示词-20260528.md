# 创AI申报信息图风格系统与 Roil 提示词

本稿用于解决两个问题：

- 现在生成的图偏线稿，不够适合申报 `PPT`
- 现在生成的图又过于统一，像同一个模板重复复制

目标不是让每张图都完全不同，而是建立“同一项目下的多子风格系统”。

## 一、总视觉方向

统一基调：

- 教育类信息图
- 申报 `PPT` 可直接使用
- 有手绘温度，但不是线稿图
- 有色块填充、层级、标签、卡片
- 白底或浅米底，适合排版
- 中文短标题可控

明确避免：

- 纯线稿流程图
- 工程蓝图风格
- 单色 wireframe
- 太像 SaaS dashboard
- 太像儿童卡通插画

## 二、统一元素

所有图共享以下公共语言：

- 配色母体：`深蓝 + 墨绿 + 橙色 + 米白`
- 局部强调色可轮换：`黄绿 / 珊瑚红 / 青蓝`
- 元素语言：圆角卡片、手写标签、小箭头、贴纸式标题条、轻颗粒纹理
- 文本控制：只保留极少量中文短词，不写长段文字
- 材质：彩色马克笔 + 水粉填充 + 纸张拼贴感

## 三、三种子风格

### A. 策略映射图

适用页面：

- 第 `2` 页：课堂痛点 -> 平台能力
- 第 `3` 页：总体解决方案

视觉特征：

- 块面清楚
- 左中右或上中下结构
- 大色块 + 连线 + 关系箭头
- 偏“教学策略海报”

### B. 学习流程图

适用页面：

- 第 `4` 页：学习闭环
- 第 `6` 页：样例任务链条
- 第 `7` 页：课堂应用流程

视觉特征：

- 更强调路径感和动作感
- 可用弧线、带状路径、编号步骤
- 每步是一个小场景，不是单纯方框

### C. 证据总结图

适用页面：

- 第 `8` 页：应用价值
- 第 `8` 页：AI 辅助开发作用

视觉特征：

- 卡片拼贴、数据板、便签板
- 信息密度略高
- 适合“结论归纳”和“证据归拢”

## 四、全局 Roil 提示词母版

以下内容作为所有图的共同前缀：

```text
面向教师申报PPT的高质量中文教育信息图，白色或浅米色背景，非线稿，使用大面积柔和色块填充、圆角卡片、轻颗粒纸张质感、少量手绘箭头和标签，视觉清晰，结构化强，适合直接放入正式汇报PPT。整体风格统一为教育类 editorial infographic，配色以深蓝、墨绿、橙色、米白为主，可加入少量青蓝或黄绿点缀。不要纯黑白线框，不要工程蓝图，不要过度扁平商务图标风，不要复杂长段文字，不要乱码，只出现指定中文短词。
```

## 六、风格差异控制规则

为了避免“风格一致性太高”，每类图做下面的控制：

- 图 `1-2` 用“策略映射图”子风格：
  更整齐、更块状、更偏海报
- 图 `3-4` 用“学习流程图”子风格：
  更有路径、更有运动感
- 图 `5` 用“证据总结图”子风格：
  更像拼贴卡片和总结板

同时保持：

- 配色母体一致
- 材质一致
- 标签语言一致

这样会形成“同项目下的家族感”，但不会像一个模板反复复制。

## 七、生成建议

建议先出下面三张确认方向：

1. 课堂问题与平台回应
2. 学习闭环
3. AI辅助开发作用

如果这三张方向对，再继续批量生成其余图。
