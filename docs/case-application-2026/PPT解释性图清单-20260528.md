# 创AI申报PPT解释性图清单

本清单专门解决一个问题：
除了真实证据图之外，当前这套 `PPT` 还需要哪些“解释性图”，才能把项目讲清楚。

这里的“解释性图”不是课堂照片、学生作品、AI 对话截图这类证据图，
而是帮助评审快速理解逻辑、结构、流程、关系的图。

## 一、先区分两类图

整套 `PPT` 里应该同时有两类图：

### 1. 证据图

作用：

- 证明这件事真的做过
- 证明它在真实课堂中出现过
- 证明学生真的产出了结果

典型例子：

- 课堂照片
- 学生作品
- Blockly 截图
- Jupyter 运行截图
- AI 对话截图

### 2. 解释性图

作用：

- 帮评审快速理解“为什么这样设计”
- 帮评审理解“平台是怎么串起来的”
- 帮评审理解“学生是怎么学的”

典型例子：

- 问题-方案图
- 学习闭环图
- 课堂流程图
- 课程资源结构图
- 任务链条图

当前这套 `PPT` 最大的问题之一，就是证据图和解释性图的配比还不够稳。
所以后面要主动补“解释性图”。

## 二、建议新增或强化的解释性图

下面这些图不是可有可无，而是建议作为正式版 `PPT` 的核心说明图。

## 图 1：课堂痛点 -> 平台能力映射图

用途：

- 用在第 `2` 页
- 一眼讲清楚为什么要做这个工具

这张图要回答的问题：

- 课堂里到底难在哪
- 平台分别用什么能力去解决

建议图结构：

- 左侧：`课堂问题`
- 中间：`平台能力`
- 右侧：`教学改进结果`

建议文案骨架：

- 课堂问题：
  `工具切换多`
  `环境配置复杂`
  `学习路径割裂`
  `课程资源难复用`
- 平台能力：
  `统一课堂入口`
  `本地运行支撑`
  `Blockly + Jupyter 连续学习`
  `课程包结构化管理`
- 教学结果：
  `进入更快`
  `理解更连贯`
  `课堂更稳定`
  `资源可共享`

推荐图形形式：

- 三列映射图
- 箭头或连线关系图

不建议：

- 单纯放一张背景图
- 只写长段文字

建议图结构：

- 中层：`XEdu Client 统一工作台`
- 底层：`讲解页 / Blockly / Jupyter / 结果输出`
- 右侧或底部：`本地服务 / 运行支撑 / 课程共享`

推荐图形形式：

- 分层结构图
- 中心枢纽图

图上建议出现的关键词：

- `课程资源`
- `统一入口`
- `Blockly`
- `Jupyter`
- `本地运行`
- `结果复盘`

这张图的价值：

## 三、如果只能优先做 5 张解释性图，先做这 5 张

如果时间有限，优先级最高的是：

1. 课堂痛点 -> 平台能力映射图
2. 平台总体解决方案图
3. 学生学习闭环图
4. 样例任务链条图
5. AI 辅助开发作用图

这 `5` 张图补上后，整套 `PPT` 的逻辑清晰度会明显提升。

## 五、解释性图的绘制原则

后面不管你是自己画，还是我来帮你整理给设计/脚本生成，都建议遵守这几个原则：

- 一张图只讲一件事
- 图中文字尽量短，不写大段说明
- 解释性图负责“讲清楚”
- 证据图负责“证明做过”
- 不要让一张图同时承担“结构图、流程图、数据图、宣传图”四种任务
- 如果是真实证据页，解释性图可以做辅助，但不能抢主角

## 七、结论

你现在要的“更多解释性图”是对的。

因为一套强申报 `PPT` 不能只靠：

- 产品截图
- 课堂照片
- 学生作品

还必须靠解释性图把逻辑讲顺。

简单说，后面这套 `PPT` 应该这样配图：

- 用解释性图负责“讲明白”
- 用证据图负责“讲真实”

两类图都齐了，这套 `PPT` 才会真正像申报材料，而不是项目展示稿。
