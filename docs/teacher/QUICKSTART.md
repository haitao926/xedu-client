# XEdu Client 教师快速开始

适用版本：`2.0.0`
发布日期：`2026-07-16`
目标：10 分钟完成第一个 Scratch 课程。

## 1. 课堂前准备

先准备好这 3 项：

1. 已安装的教师版 XEdu Client。
2. 一个已经解压好的课程目录，或一个完整的 ZIP 课程包。
3. 一份 Scratch `.sb3` 实验文件。

如果是第一次使用，再准备一个 Python 3.10+ 独立环境，并安装 `xedu-python>=2.0.0` 及课程所需依赖。打开应用后到“Python”设置按“选择、确认、测试、保存”完成检测；发布包不会自动带入 Python 环境。

如果你准备的是旧课程，其中的 Blockly 实验只会显示“该实验类型已不再支持”；新课请直接使用 Scratch。

## 2. 10 分钟流程

| 时间 | 操作 | 结果 |
|---|---|---|
| 0-2 分钟 | 打开应用，进入教师模式 | 可以看到课程资源和课堂能力 |
| 2-4 分钟 | 导入课程包或本地课程目录 | 课程出现在“我的课程”里 |
| 4-6 分钟 | 打开第一节课的 Scratch 实验 | 进入 `.sb3` 课件或项目 |
| 6-8 分钟 | 运行一组示例积木并保存项目 | 确认 Scratch 可用、可保存 |
| 8-10 分钟 | 开启课堂 | 学生可以进入当前课节 |

### 导入完整 ZIP 课程包

进入教师模式的课程资源页，打开“导入课程”，把完整的 `.zip` 文件拖入课程包区域。应用会自动校验、解压并加入课程列表，不需要手动填写保存位置；默认目录是 `~/Documents/XeduCourses/<course-id>`。也可以使用“选择 ZIP”作为备用入口。

## 3. 第一个 Scratch 课程怎么上

1. 打开课程资源，找到第一节课。
2. 进入该课的 Scratch 实验。
3. 打开课程配套的 `.sb3` 项目。
4. 运行一次示例积木，确认右侧结果和项目状态正常。
5. 点击保存。
6. 返回课堂页，开启当前课节课堂。

### 课堂中建议教师做的事

- 先让学生完成打开项目和运行示例。
- 再让学生修改一个积木参数，重新运行。
- 最后让学生保存并重开一次项目。

## 4. 学生进入课堂

1. 教师开启课堂后，学生从课堂入口进入。
2. 如果自动发现成功，学生直接点课堂卡片。
3. 如果自动发现失败，改用教师机的手动地址，见 [课堂网络说明](CLASSROOM_NETWORK.md)。

## 5. 本次课结束后

1. 确认 Scratch 项目已经保存。
2. 记录今天用到的课程版本。
3. 如果你改了课程目录，先做备份，再进行后续更新或发布。
