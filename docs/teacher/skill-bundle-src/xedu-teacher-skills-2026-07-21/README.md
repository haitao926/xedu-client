# XEdu Teacher Skills Bundle

本压缩包用于给培训老师或参训老师安装常用 XEdu Codex skills。

## 包含内容

- `xedu-pack`
- `xedu-course-builder`
- `xedu-html-lab`
- `xedu-scratch-lab`
- `xedu-jupyter-lab`

## 使用场景

- 培训现场统一分发 skill
- 老师课后自行安装常用 XEdu skill
- 教研组在多台机器上保持相同 skill 集合

## 目录说明

请保留 `skills/` 下每个 skill 的完整文件夹，不要只取 `SKILL.md`。
