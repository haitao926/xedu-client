# XEdu Teacher Skills 安装说明

## 安装步骤

1. 解压 `xedu-teacher-skills-2026-07-21.zip`
2. 进入解压后的 `skills/` 目录
3. 将里面的 skill 文件夹整体复制到本机 Codex skill 目录
4. 重新打开 Codex，或开始新的对话轮次

## 常见目录

- macOS: `~/.codex/skills/`
- Windows: `%USERPROFILE%\\.codex\\skills\\`

## 注意事项

- 不要只复制 `SKILL.md`
- 必须复制整个 skill 文件夹
- 如果外层目录套了两层，Codex 可能无法识别
- 如本机已有同名 skill，先做好备份，再覆盖
