# HTML Lab

Build a focused classroom page rather than a marketing site.

## Required Experience

- Put the interaction, observable result, and copyable code in or near the first viewport.
- Make meaningful controls update both the visible result and the exact displayed Python snippet.
- Keep one page centered on one phenomenon and one short learner challenge.
- Use the actual XEdu API source or a verified local example. Preserve exact imports, parameters, model names, and return shapes.
- Prefer local assets and offline behavior when the experiment permits it.

## Verification

Exercise every control and confirm state, result, and code stay synchronized. Check keyboard use, labels, contrast, projection readability, and common desktop and mobile widths. If the Python path cannot run locally, distinguish static code linkage from runtime verification.
