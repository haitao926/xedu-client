# ESP32 MicroPython 实验快速开始

## 使用前

- 使用 USB 数据线连接 ESP32。
- 确认开发板已经刷入 MicroPython 固件。
- 在课程资源中打开一个 ESP32 MicroPython 实验。
- 实验代码使用 `.py` 文件，默认运行当前打开的文件。

## 学生操作

1. 从课程实验进入 JupyterLab。
2. 在 JupyterLab 启动器或命令面板中打开“ESP32 实验”。
3. 在右侧面板选择 ESP32 串口并点击“连接开发板”。
4. 打开实验提供的 `.py` 文件，点击“运行到 ESP32”。
5. 在“设备输出”区域观察传感器、LED 或其他硬件现象对应的输出。
6. 修改代码后再次运行；程序失控时点击“停止运行”，需要重新开始时点击“重启设备”。

## 常见问题

- **没有串口**：检查 USB 是否支持数据传输，并确认系统已安装 CH340、CP210x 或板卡对应的串口驱动。
- **串口被占用**：关闭其他串口监视器、Arduino Serial Monitor 或 Thonny 后重试。
- **没有 MicroPython 提示**：开发板可能还没有刷入 MicroPython 固件，第一版 XEdu Client 不负责固件刷写。
- **运行没有输出**：确认运行的是当前打开的 `.py` 文件，并在代码中使用 `print()` 输出观察信息。
