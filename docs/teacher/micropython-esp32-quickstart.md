# ESP32 MicroPython 实验快速开始

## 使用前

- 使用 USB 数据线连接 ESP32 / ESP32-S2 / ESP32-S3 / ESP32-C3。
- 确认开发板已经刷入 MicroPython 固件。第一版 XEdu Client 不负责固件刷写。
- 在课程资源中打开一个 ESP32 MicroPython 实验。实验代码使用 `.py` 文件。
- 默认波特率为 `115200`。

## 学生操作

1. 从课程实验进入 JupyterLab。普通 Python 笔记本实验不受影响。
2. 在 JupyterLab 启动器或命令面板中打开“ESP32 实验”，右侧会出现硬件面板。
3. 打开实验提供的 `.py` 文件（面板会记住这个文件，即使随后点击了右侧面板）。
4. 点击“刷新”，选择 ESP32 串口，再点击“连接开发板”。连接成功后应看到 MicroPython 提示符 `>>>`。
5. 点击“运行到 ESP32”，在“设备输出”中观察 `print()`、传感器或报错信息。
6. 程序失控时点击“停止运行”（相当于 Ctrl+C）；需要重新开始时点击“重启设备”。实验结束点击“断开连接”，避免占用串口。

## 常见问题

- **没有串口**：显示“未发现 ESP32，请检查 USB 数据线和驱动”。请确认 USB 线支持数据传输，并安装 CH340、CP210x、或板卡对应驱动。
- **串口被占用**：显示“串口正在被其他程序使用，请关闭串口监视器后重试”。请关闭 Thonny、Arduino Serial Monitor 或其他串口工具后再连接。
- **没有 MicroPython 提示**：显示“设备没有返回 MicroPython REPL，请先准备固件”。开发板可能还没有刷入 MicroPython，或需要重新插拔 USB。
- **运行超时**：已有输出会保留。请先“停止运行”或“重启设备”，再重新运行当前 `.py` 文件。
- **运行没有输出**：确认运行的是当前打开的 `.py` 文件，并在代码中使用 `print()`。
