# XEdu Client 教师故障排查

适用版本：`2.0.0`
发布日期：`2026-07-16`
主线说明：Scratch 是当前唯一图形化编程主线；旧 Blockly 实验只显示不支持提示。

## 1. Python 环境未配置或检测失败

教师版发布包不包含 `python_env`。首次启动或换电脑后，请在“Python”设置中选择本机 Python 3.10+ 可执行文件：Windows 选择 `Scripts\\python.exe`，macOS 选择 `bin/python3` 或 `bin/python`。

如果检测失败：

1. 确认选择的是 Python 可执行文件，不是环境目录或 `pip` 文件。
2. 确认版本至少为 Python 3.10。
3. 在该环境中安装课程依赖，再回到应用点击“测试”。
4. 如果显示 `xedu-python>=2.0.0` 但兼容性异常，点击“修复兼容性”，完成后再次点击“测试”。该操作只会移除已确认的两条旧元数据上限，不会自动升级其他包。
5. XEduHub 探针通过后点击“保存设置”，再启动 Jupyter。

如果后端尚未启动，首页的“选择本机 Python”按钮会在选择后自动重试；不需要把 Python 文件复制到安装目录。

## 2. 应用启动后是空白页

先看这三项：

1. 等待后端完全启动，不要立刻反复重开。
2. 关闭后重新打开应用一次。
3. 如果仍然空白，收集日志后再联系支持。

## 3. Scratch 页面打不开或提示编辑器不可用

先确认你拿到的是正式教师包，而不是源码目录。

如果页面提示 Scratch 编辑器资源不存在，通常表示安装包不完整或使用了旧包。处理顺序如下：

1. 退出应用。
2. 重新安装当前发布包。
3. 再打开 Scratch 课程。

## 4. 学生找不到课堂

按这个顺序排查：

1. 先确认教师已经开启课堂。
2. 再确认学生和教师在同一网段。
3. 如果自动发现失败，改用手动地址。
4. 如果跨 VLAN，优先让网络管理员放通，或者改成同网段试点。

手动地址格式见 [课堂网络说明](CLASSROOM_NETWORK.md)。

## 5. 课堂能打开，但网络资源不稳定

这种情况通常是网络边界问题，不是课程问题。

- 本地已导入的课程通常可以继续运行。
- 云端导入、课程同步、远端拉取和升级需要联网。
- 如果课前知道现场可能离线，先把课程和素材导入本机。

## 6. 拉取课程提示 `Request timeout after 25000ms`

大课程包可能需要超过 25 秒，提示不代表任务一定没有开始。新版会先创建后台传输任务，并在课程详情中显示下载、校验、备份和写入进度；请等待进度进入完成或错误状态，不要连续重复点击。

如果任务明确失败：

1. 检查资源库地址、网络连接和 Gitea Token。
2. 重新发起一次拉取；已有本地课程会先备份到 `.xedu_backup`。
3. 如果应用刚刚重启，旧的内存任务无法继续，重新发起导入即可。

## 7. ZIP 课程包导入失败

课程包必须包含有效的 `course.json`。不支持路径穿越、重复路径、符号链接、损坏 ZIP 或超过解压限制的压缩包；校验失败不会覆盖已有课程。

## 8. 日志在哪里

主要后端日志在用户数据目录的 `logs/backend-process.log`。

常见位置：

- Windows: `%APPDATA%\XeduClient\logs\backend-process.log`
- macOS: `~/Library/Application Support/XeduClient/logs/backend-process.log`

如果你还要看 Jupyter 启动日志，也在同一 `logs` 目录里。

## 9. 配置和课程怎么备份

### 配置备份

应用保存配置时，会自动写入配置备份：

```text
<用户数据目录>/config/backups/config_*.json
```

### 课程备份

课程同步和覆盖前会在课程目录旁边保留备份，常见位置是：

```text
<课程目录>/.xedu_backup/<课程名>/
```

### 手工备份建议

升级前，建议你额外复制这两类内容：

1. 课程目录
2. 用户数据目录下的 `config` 目录

## 10. 怎么升级

当前没有自动更新入口，升级时按下面做：

1. 备份课程目录和配置目录。
2. 关闭正在运行的 XEdu Client。
3. 安装或解压新的教师版发布包。
4. 重新打开应用，确认课程仍能加载。

如果升级后出现异常，先恢复上一版发布包，再把日志发给支持人员。

## 11. 常见恢复动作

- 课程目录损坏：从备份目录恢复最近一次可用版本。
- 配置异常：删除有问题的配置文件，让应用重新生成默认配置。
- 课堂地址失效：重新查看教师机 IPv4，再让学生手动输入。
- 旧 Blockly 课程显示不支持：这是预期行为。请改用课程中的 Scratch 资源，或联系课程维护者补充 Scratch 版本。
