# XEdu Client 课堂网络说明

适用版本：`2.0.0`
发布日期：`2026-07-16`

## 1. 默认连接方式

教师开启课堂后，学生端会自动发现课堂。

这种方式适合：

- 教师机和学生机在同一网段
- 学校网络允许局域网广播
- 没有特别严格的无线隔离或 VLAN 限制

## 2. 手动地址怎么填

如果自动发现失败，直接把教师机的局域网地址告诉学生。

格式如下：

```text
http://<教师机IPv4>:5123
```

示例：

```text
http://192.168.1.23:5123
```

填写时请注意：

- 只能填学生机能访问到的教师机 IPv4 地址
- 不要填 `127.0.0.1` 或 `localhost`
- 不要填浏览器里看起来像“本机地址”的地址

## 3. 哪些网络最容易失败

- 学校把学生机和教师机分到了不同 VLAN
- 无线客户端隔离打开了
- 学校防火墙拦截了教师机的 `5123` 端口
- 教师机连了多个网卡，学生拿到的是不能访问的地址

## 4. 教师开课前的网络检查

1. 确认教师机和学生机在同一个可互访网络里。
2. 确认教师机的防火墙允许课堂访问。
3. 确认手动地址能从学生机打开。
4. 确认学生机打开的是课堂地址，不是教师机本地回环地址。

## 5. 现场建议

- 先让 1 台学生机试连，确认地址正确后再让全班进入。
- 如果自动发现失败，不要反复重启应用，先改用手动地址。
- 如果课堂跨 VLAN，优先找网管放通，或直接改用同网段试点。
