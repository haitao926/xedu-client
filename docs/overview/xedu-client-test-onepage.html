1. 安装启动

先确认安装包能正常打开
  • mac：打开 `XEdu Client-2.0.0-arm64-mac.zip` 并启动 App
  • win：运行 `XEdu Client-2.0.0.exe` 完成安装
  • 预期： 应用启动正常，页面不是空白

2. 角色模式

学生默认进入，教师需解锁
  • 学生模式仅显示：主控台 / AI 助手 / 文档中心
  • 教师登录后显示：课程资源 / 设置
  • 预期： 退出教师模式后教师入口消失

3. 课堂功能

重点看“进入即上课”是否成立
  • 教师在课节页开启“第 N 节课堂”
  • 学生在主控台的“课堂接入”点击课堂卡片进入
  • 预期： 不输课堂口令，不再确认路径，直接进入当前课节实验

4. 课程资源

课程包导入、云端导入都要通
  • 课程包导入：能读 `xedu-pack` 产出的 `course.json`
  • 云端导入：输入公开仓库地址后可读取并导入
  • 预期： 导入后能看到课节和实验结构

5. 实验访问

HTML 和 Notebook 都要能打开
  • 打开一个同时包含 `html` 和 `ipynb` 的实验
  • 点击“打开 HTML”
  • 点击“进入 Notebook”
  • 预期： HTML 直接打开，Notebook 在主控台打开

6. Gitea 同步

一门课一个仓库
  • 首次上传：填写资源库地址 / 仓库路径 / 分支
  • 上传更新：修改本地课程后点击“上传更新”
  • 拉取更新：远端有新版本后点击“拉取更新”
  • 预期： 本地已改动时会先提示确认
