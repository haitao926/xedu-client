XEdu Client · 项目概览

面向课堂教学的桌面化 Jupyter 学习与课程管理客户端

XEdu Client 是一个基于 Electron + Python 的桌面应用，围绕教学现场提供 Jupyter 启动管理、课程资源组织、教师/学生双角色使用、AI 助手与课程发布同步能力。 它的目标不是单纯打开 Notebook，而是把“上课、备课、管课、发布课程”串成一个完整流程。

版本：2.0.0 桌面端：Electron 后端：Python Flask 核心场景：课堂教学 / 实验课 / 课程资源管理

项目定位

该项目面向学校教学和实验教学场景，解决传统 Jupyter 工具“只会运行，不会组织教学”的问题。 学生侧聚焦进入课堂、打开实验和跟随学习；教师侧聚焦课程创建、课节管理、实验材料整理、课堂开启与课程发布。

核心能力

  • Jupyter 管理：启动、挂载、进入指定实验目录，作为课堂实验运行底座。
  • 课程资源：支持课程、课节、实验三级结构组织，适合按教学逻辑管理内容。
  • 角色区分：学生模式与教师模式分离，教师功能默认隐藏，减少误操作。
  • 课程同步：支持本地课程、云端课程、仓库发布与更新拉取。
  • AI 助手：为课堂中的代码理解、问答和实验辅助提供入口。

典型使用流程

  • 教师备课：创建课程，设计课节与实验，整理 Notebook、HTML 与素材文件。
  • 教师上课：开启课堂，进入指定课节实验，让学生按统一路径开始操作。
  • 学生学习：直接进入课堂实验，在主控台中打开 Jupyter 并完成实验。
  • 课程沉淀：将课程发布到仓库，后续持续更新、拉取和复用。

技术架构

  • 前端：原生 HTML / CSS / JavaScript，负责课程界面、课堂入口和交互逻辑。
  • 桌面壳：Electron，负责窗口管理、本地能力调用和 Jupyter 视图承载。
  • 后端服务：Python Flask，负责配置、课程接口、Jupyter 控制与资源同步。
  • 运行环境：内置 Python 环境，支持 Mac 与 Windows 桌面分发。

当前项目价值

XEdu Client 的价值在于把“实验运行工具”升级成“教学工作台”。它不仅面向单个 Notebook， 更面向完整课程生命周期：本地创建、课堂使用、云端同步、后续维护。对于需要统一教学入口、 降低学生操作复杂度、同时保留教师管理能力的学校场景，这个方向是成立的。
