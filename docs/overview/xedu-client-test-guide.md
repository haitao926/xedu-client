# XEdu Client 测试说明

适用版本：`2.0.0`

## 测试数据

- 公开课程仓库：`http://8.145.44.54:3000/admin/zhangjiang-image-recognition`
- 资源库地址：`http://8.145.44.54:3000`
- 仓库路径：`admin/zhangjiang-image-recognition`
- 分支：`main`
- 本地课程目录建议：
  - mac：`/Users/<用户名>/Documents/XEduCourses`
  - win：`C:\\Users\\<用户名>\\Documents\\XEduCourses`

## 1. 安装启动

### mac

- 打开 `dist-final/XEdu Client-2.0.0-arm64-mac.zip`
- 解压后启动 `XEdu Client.app`
- 预期：应用能打开，页面不是空白

### win

- 运行 `dist-final/XEdu Client-2.0.0.exe`
- 完成安装后启动
- 预期：应用能打开，页面不是空白

## 2. 角色模式

### 学生模式

- 默认进入学生模式
- 预期：左侧只显示 `主控台`、`AI 助手`、`文档中心`
- 预期：不显示“课程资源”“设置”

### 教师模式

- 点击顶部 `教师登录`
- 输入教师口令
- 预期：登录后显示“课程资源”“设置”
- 再次点击退出
- 预期：回到学生模式

## 3. 课堂功能

### 教师开启课堂

- 教师登录后进入“课程资源”
- 打开本地课程
- 在课节页点击 `开启第 N 节课堂`
- 预期：开启的是当前课节，不是整门课默认第一节

### 学生进入课堂

- 学生模式进入“主控台” -> `课堂接入`
- 点击课堂卡片
- 预期：
  - 不需要输入课堂口令
  - 不需要再手动确认项目路径
  - 直接进入当前课节对应实验
  - 如果当前课节有 Notebook，直接打开该 Notebook

### Jupyter 联动

- 未进入课堂时
- 预期：不会自动跳到 Jupyter
- 有弹窗时
- 预期：Jupyter 不遮挡弹窗

## 4. 课程资源

### 导入课程入口

- 点击 `导入课程`
- 预期：
  - 默认进入 `课程包导入`
  - 可切换到 `云端导入`
  - 不再出现“新建课程”或“导入本地课程”入口

### Skill 课程包导入

- 点击 `导入课程`
- 保持在 `课程包导入`
- 选择一个 `xedu-pack` 生成的 zip 课程包或已解压目录
- 再选择本地保存位置并执行导入
- 预期：
  - 能读取课程包中的 `course.json`
  - 能看到课节和实验结构
  - 导入后可保存到“我的课程”

### 云端导入公开课程

- 点击 `导入课程`
- 切换到 `云端导入`
- 选择本地保存目录
- 输入：`http://8.145.44.54:3000/admin/zhangjiang-image-recognition`
- 点击读取并导入
- 预期：
  - 能直接读取课程
  - 能看到课节和实验结构
  - 导入后出现在“我的课程”

### 云端导入私有课程

- 输入私有仓库地址
- 先不填 Token 读取
- 再补 Token 重试
- 预期：
  - 无 Token 时读取失败
  - 补 Token 后读取成功

## 5. 实验访问

- 打开一个含 `html` 和 `ipynb` 的实验
- 点击 `打开 HTML`
- 点击 `进入 Notebook`
- 预期：
  - HTML 能打开
  - Notebook 能在主控台中打开

### 材料文件夹挂载

- 在课程资源中给某个实验点击 `选择材料文件夹`
- 选择课程根目录内的子文件夹
- 预期：
  - 能读取该文件夹中的实验文件
  - 文件数会显示在实验材料项中
  - 保存后课程结构中会记录这些文件

- 再选择课程根目录外的文件夹
- 预期：
  - 返回明确错误
  - 不会写入非法路径

## 6. Gitea 同步

### 首次上传课程

- 打开未绑定仓库的本地课程
- 点击 `上传课程`
- 填：
  - 资源库地址：`http://8.145.44.54:3000`
  - 仓库路径：`<owner>/<repo>`
  - 分支：`main`
- 预期：
  - 上传成功
  - 课程绑定远端仓库
  - 按钮变为 `上传更新`、`拉取更新`

### 上传更新

- 修改本地课程
- 点击 `上传更新`
- 预期：更新成功；私有仓库或写操作需要 Token

### 拉取更新

- 先让远端课程有新版本
- 点击 `拉取更新`
- 预期：
  - 本地没改动：直接更新
  - 本地有改动：先提示确认，再更新
  - 成功提示为 `课程已更新到本地。`

## 7. 最小回归

上线前至少检查这 8 项：

1. 学生模式正常
2. 教师登录正常
3. 课程包导入入口正常
4. 云端导入公开课程正常
5. 上传课程正常
6. 拉取更新正常
7. 开启课堂正常
8. 学生进入课堂后直接进入当前课节实验

## 8. 注意事项

- mac 包当前未签名，首次打开可能需要手动放行
- 发布到 Gitea 属于写操作，通常需要 Token
- 拉取更新前的自动备份用于防止本地修改被覆盖
