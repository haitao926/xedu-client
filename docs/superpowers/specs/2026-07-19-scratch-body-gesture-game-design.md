# 人体关键点体感越障实验设计

## 目标

将“人体姿态控制行空板 K10”的实验 2 从坐标读取演示改为可展示的
Scratch 单关游戏“举手跳跃：体感越障”。学生从摄像头原始关键点出发，
自行完成姿态判断，并用结果控制游戏角色跳过障碍。

## 范围与约束

- 仅修改本机课程目录 `~/Documents/XeduCourses/human-pose-control-hardware` 的实验 2。
- 保留 `pose_body17`、`xeduCamera` 和 `xeduBodySensing`；不引入依赖或新的感知接口。
- 使用鼻尖、左手腕和右手腕的舞台 Y 坐标。双手腕均高于鼻尖时触发跳跃。
- 使用已实现的“显示身体关键点”积木作为可视化调试层。
- 课程保持单关、单核心动作，保证一个课时内可完成。

## 学生体验

1. 点击绿旗，开启摄像头、人体感知和身体关键点显示。
2. 学生读取鼻尖与两只手腕的 Y 坐标，完成“双手举起”的条件判断。
3. 条件满足时发送“跳跃”消息，由游戏角色越过持续出现的障碍物。
4. 角色碰到障碍时结束本局并显示分数；重新开始可调节动作阈值并再次验证。

项目预置角色、障碍、计分、碰撞和重开逻辑。感知启动、坐标读取、姿态条件与
跳跃消息必须由学生搭建，避免把 AI 判断封装成不可理解的黑盒。

## 课程材料

- 以新的 Scratch 项目替换原 `keypoint_coordinates.sb3`，保留同一文件名以避免课程路径变化。
- 更新 Scratch README，说明任务、关键点条件、验证步骤和挑战任务。
- 更新 `course.json` 的实验 2 标题、描述和学生任务，使资源页与项目一致。

## 验收

- 打开项目后可看到摄像头预览和关键点叠加层。
- 学生可用鼻尖与两手腕的 Y 坐标搭建条件；未完成条件时不跳跃。
- 补全条件并发送“跳跃”后，角色能越过障碍、累积分数并在碰撞后结束。
- README 和课程资源页清楚区分预置游戏骨架与学生需要完成的感知逻辑。

## 非目标

- 不做多关卡、多人对战、动作分类模型训练或 K10 实机控制。
- 不使用固定像素坐标来定义学生动作，也不在本实验中加入新的身体关键点菜单。
