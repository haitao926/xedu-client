# Xedu Client v2.0 安装包说明

## 📦 安装包文件

现在您有两个安装包可选择：

### 🎯 **完整安装包** (推荐)
- **文件名**: `XeduClient-Complete-v2.0.tar.gz` (131 MB)
- **包含内容**:
  ```
  XeduClient-Complete-v2.0/
  ├── 一键安装.bat          # 🔧 自动安装程序
  ├── 启动Xedu Client.bat    # 🚀 启动脚本
  ├── 卸载程序.bat          # 🗑️ 卸载工具
  ├── README.txt            # 📖 详细说明文档
  └── Xedu Client/          # 📁 主应用程序
      ├── Xedu Client.exe   # 主程序
      ├── resources/        # 资源文件
      └── [其他运行时文件]
  ```

### 📱 **便携版**
- **文件名**: `XeduClient-Installer-v2.0.tar.gz` (131 MB)
- **适合**: 开发者或需要绿色安装的用户

## 🚀 安装方法

### 方法1：一键安装（推荐新手用户）
1. 下载 `XeduClient-Complete-v2.0.tar.gz`
2. 解压到任意位置
3. **右键**点击 `一键安装.bat` → **"以管理员身份运行"**
4. 按提示完成安装
5. 在桌面或开始菜单找到启动图标

### 方法2：手动安装（推荐高级用户）
1. 下载并解压 `XeduClient-Complete-v2.0.tar.gz`
2. 将整个文件夹复制到 `C:\Program Files\XeduClient`
3. 双击运行 `启动Xedu Client.bat`

### 方法3：便携模式
1. 下载 `XeduClient-Installer-v2.0.tar.gz`
2. 解压到U盘或任意目录
3. 进入 `Xedu Client` 文件夹
4. 双击运行 `Xedu Client.exe`

## ⚠️ 重要提醒

1. **Python环境**: 使用前请确保已安装 Python 3.9+
2. **首次运行**: 首次启动会进行环境配置，请耐心等待
3. **防火墙**: 如有安全提示，请允许程序访问网络
4. **管理员权限**: 推荐以管理员身份运行安装程序

## 🆘 常见问题解决

### Q: 启动时提示"未检测到Python"
A: 请从 https://python.org 下载安装Python

### Q: 安装程序无法创建快捷方式
A: 请右键"以管理员身份运行"安装程序

### Q: 程序启动后没有响应
A: 检查Python是否正确安装，或尝试以管理员身份运行

### Q: AI助手功能无法使用
A: 需要在设置中配置有效的API密钥
