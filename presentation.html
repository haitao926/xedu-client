1. 什么是 XEdu？

基于 OpenXLab (上海人工智能实验室) 的教育版

一套完整的 AI 学习与开发工具

核心理念

💡 极简理念：代码最简，开箱即用

🚀 应用先行：先应用，再理解

🎓 适用对象：

  • 中小学 AI 教育
  • 高校 AI 通识课程
  • AI 初学者

2. XEdu Client 的核心价值

痛点 😫

  • Python 环境配置繁琐
  • 依赖安装经常报错
  • 命令行操作劝退新手

解决方案 💊

  • 一键启动 Jupyter Notebook
  • 自动管理 Python 环境
  • 可视化的 Electron 界面

🤖 内置 AI 智能助手

  • 集成 Kimi AI / OpenAI Compatible API
  • 支持 视觉识别：截图提问，报错分析
  • 代码辅助：实时生成与解释代码

⚙️ 自动化与配置

  • 环境检测：自动识别 Conda/Python 路径
  • 项目管理：拖拽切换工作目录
  • 系统设置：可视化配置 API Key 和端口

4. XEdu 强大的工具生态

Client 只是入口，背后是强大的库支持

  • MMEdu (计算机视觉): 基于 OpenMMLab，支持图像分类、检测
  • BaseNN (神经网络): 类 Keras 语法的神经网络搭建
  • BaseML (机器学习): 类 Sklearn 语法的传统机器学习
  • BaseDT (数据处理): 一行代码完成数据清洗
  • XEduLLM (大模型): 轻松开发智能体应用
