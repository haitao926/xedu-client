## 02 Problem

主标题：AI 实验课为什么总是上不顺？
三组问题：上不起来 / 连不起来 / 留不下来
结论：问题不在学生不努力，而在工具把太多无关操作推给了课堂。

## 03 Learning Path

主标题：从体验，到实践
中心：同一个 AI 问题
三个入口：HTML 先观察 / Scratch 让流程可见 / Jupyter 进入真实代码
脚注：不是固定流水线，而是为不同学习目标提供不同入口。

## 04 Product Response

主标题：把一节 AI 实验课放进一张工作台
三组回应：实验上不起来→统一入口 + 环境检查；学习连不起来→课程包 + 多形态实验；课程留不下来→导入 + 更新 + 复用。

## 05 CTA

主标题：一节课，可以这样发生
课前：选择 Python / 导入课程 / 完成预检
课中：开启课堂 / 学生进入 / 完成实验
课后：备份课程 / 更新资源 / 继续使用
结论：让 AI 实验课从偶尔成功的展示，变成普通机房里可以稳定发生的学习。
