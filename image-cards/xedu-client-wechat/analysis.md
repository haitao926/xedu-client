# 内容判断

这不是小红书式功能清单，也不是产品广告。文章的传播顺序是先让一线教师认同项目为何存在，再让真实产品证据推动试用。因此应采用 **A Story-Driven** 主策略，视觉上使用克制的 `notion` 手绘知识图，而不是可爱卡通、炫技海报或全篇截图。

## 目标读者

- **主要读者**：中小学信息科技、人工智能课程一线教师。
- **关注点**：课堂能否稳定运行、学生能否顺畅进入实验、课程能否复用。
- **视觉偏好**：真实、专业、清楚，能够快速判断“是否适合我的机房课堂”。
- **排斥项**：儿童化卡通、虚构软件界面、过度营销、功能大而全的假象。

## 钩子分析

**标题钩子评分：4/5**

- 有明确转变：“能演示”到“能日常开展”。
- 有教师身份共鸣：实验课被环境和工具打断。
- 有项目追问：“为什么做 XEdu Client”。
- 不需要再添加夸张数字或“神器”等营销词。

## 核心视觉原则

1. **概念与关系用绘制图**：课堂中断、学习路径、AI Coding 判断、产品回应。
2. **功能和效果用真实截图**：主界面、课程资源、Scratch、课堂入口、案例实验。
3. **禁止生成虚构 UI**：SASU 只画概念图，不替代真实产品截图。
4. **禁止复用旧 Blockly 图**：仓库既有申报图中大量出现 Blockly，与当前 Scratch 主线冲突。
5. **运动会 AI 裁判案例不画 Scratch**：该课程当前只有 HTML 与 Notebook 实验。
6. **不画完整作业管理系统**：当前课堂功能是发现、拉取、索引和实验入口。

# 推荐图组

## 01 封面图：从课堂中断到连续实验

- **类型**：生成图，公众号封面。
- **作用**：建立项目第一印象，不承担功能说明。
- **画面**：普通学校机房，教师与学生面对同一任务；左侧隐约出现被关闭的终端和中断符号，右侧收束为 XEdu Client 统一工作台，学习重新向前。
- **文字**：只保留 `XEdu Client` 与“让 AI 实验课连续发生”。
- **布局**：`sparse`。
- **尺寸**：先生成 `2048x1152`，构图预留中部安全区，最终发布时裁成公众号封面比例。

## 02 起源场景图：一个被关掉的黑框

- **类型**：生成图，正文情境插图。
- **作用**：把项目缘起从叙述变成一眼可懂的课堂瞬间。
- **画面**：学生误关黑色终端窗口，Jupyter 连接中断；教师在多台学生机之间排查。重点是“注意力被环境夺走”，不是把学生画得顽皮。
- **文字**：不超过两句，“实验还没开始，课堂先被环境打断”。
- **布局**：`comparison` 或 `balanced`。
- **尺寸**：`1536x1024`。

## 03 学习路径图：同一知识的三种入口

- **类型**：生成信息图，核心概念图。
- **作用**：解释 HTML、Scratch、Jupyter 的关系。
- **画面**：同一个 AI 问题位于中心，三条可选择的路径分别通向体验、流程可视化、真实代码实践；避免画成每节课必须依次通过的强制流水线。
- **关键词**：HTML“观察体验”、Scratch“流程可见”、Jupyter“代码实践”。
- **脚注**：“按学习目标选择，不必每课全部使用”。
- **布局**：`mindmap` 或非线性 `flow`。
- **尺寸**：`1536x1024`。

## 04 当前产品实证：真实界面三联图

- **类型**：真实截图组合，不使用生成模型。
- **作用**：证明这不是概念项目。
- **必须截取**：当前总控制台或学生首页、课程资源详情、内置 Scratch/XEdu AI 扩展。
- **要求**：使用同一版本、同一窗口尺寸、无个人 API Key 或教师口令；不能使用旧 Blockly 页面。
- **尺寸**：三张原始截图，公众号排版时可分别插入或组成横向三联图。

## 05 产品回应图：上不起来、连不起来、留不下来

- **类型**：生成信息图。
- **作用**：将产品能力与课堂问题一一对应，替代长功能清单。
- **三组关系**：
  - 上不起来 → 环境检查与统一启动。
  - 连不起来 → 同一课程上下文中的多形态实验。
  - 留不下来 → 标准课程包、备份、更新和复用。
- **布局**：`comparison`，三行“问题 → 回应”，不增加学习分析、作业收集等未实现能力。
- **尺寸**：`1536x1024`。

## 06 案例实证：运动会 AI 裁判

- **类型**：真实截图组合，不使用生成模型。
- **作用**：证明“体验到实践”可以落到一节具体课程。
- **必须截取**：`构建神经网络.html` 中的网络结构与参数变化、`L9_Part1.ipynb` 中的数据划分/模型训练/Loss 结果。
- **组合方式**：左侧 HTML“看见结构”，右侧 Notebook“训练验证”，中间用一句短说明连接。
- **禁止项**：不要加入 Scratch、Blockly 或与本课程无关的通用 AI 插画。

## 07 普通课堂流程：课前、课中、课后

- **类型**：真实截图为主，可辅以极简流程标签。
- **作用**：把教师的试用意愿转成可执行步骤。
- **必须截取**：Python 环境检测或课程导入、教师开启课堂、学生发现/手动加入课堂。
- **流程**：课前预检 → 课中开课与加入 → 课后备份/更新。
- **要求**：真实展示当前课堂能力，不画成绩统计、进度看板或作业回收。

# 不建议绘制

- **系统技术架构图**：文章面向一线教师，不需要 Electron、Flask、Vite 分层。
- **参考文献知识卡**：会把公众号文章重新拉回论文语气。
- **产品功能九宫格**：削弱项目缘起，容易变成说明书。
- **边界警告图**：外置 Python、本地高权限、局域网依赖用正文列表表达更准确。
- **结尾金句卡**：可选但非必要，文章已有封面与核心信息图，继续加图会稀释真实产品证据。

# 风格与版式

- **策略**：A Story-Driven。
- **风格**：`notion`，但减少传统黑白线稿的冷感，使用轻纸张纹理与 XEdu 状态色。
- **主色**：深靛蓝 `#4F46E5`、青绿 `#0F766E`、橙黄 `#B45309`。
- **背景**：暖白 `#FAFAF7`；避免整组被紫色渐变主导。
- **文字密度**：每张只保留一个结论，正文不超过 40 个中文字。
- **公众号适配**：正文图优先 `3:2` 或 `16:9` 横图；不采用小红书默认 `3:4` 竖卡。
- **一致性**：01 作为生成图视觉锚点，02、03、05 使用 01 作为参考图；真实截图不套生成的假 UI，只统一留白、标题字号和边框语气。
